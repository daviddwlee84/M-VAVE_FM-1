# CUBE 操作速查

[CUBE](cube.md) 的按鍵一覽。`HOME` 按一下回 MENU；**按住 `HOME` 0.6 秒，機器上會顯示這一頁的按鍵說明**（任一按鈕關掉）。MENU 裡 `SELECT` 選、`PLAY` 進。

## 每一頁

| 頁 | 控制 | 作用 |
|---|---|---|
| TIMER | 任一鍵 | 開始 inspection（開著時）；按住 0.3 秒放開：開始；計時中：停 |
| | `K1` | 剛結束那一筆：OK / +2 / DNF |
| | `SEL` 兩下 | 刪掉剛結束那一筆 |
| | `REC` | 換打亂 |
| CUBE | 琴鍵、`SEL` + 琴鍵 | 轉面、反方向 |
| | UNDO 鍵、`SEL` + UNDO | 退一步、回到復原 |
| | `REC` / 按住 `REC` | 跟著燈打亂 / 直接打亂好 |
| | `PLAY` | 虛擬計時（第一轉開始、復原時停） |
| | `K1` `K2` `K3` / `K4` | 繞 x、y、z 轉視角 / 斜看的 preset |
| | 只按 `SEL` | 鍵位圖 |
| ALGS | `SELECT` | 公式集 |
| | `PRESETS`、`OCT-` / `OCT+` | case |
| | `ALGORITHM` | 這個 case 的下一個公式（畫面寫「FORMULA 2 OF 3」） |
| | `K1` `K2` `K3` / `K4` | 轉 3D 視角 / preset |
| | `SEL` | 圖：從上面看（PLL 有箭頭）或 3D |
| | `PLAY` | 在方塊上播放選中的公式（燈亮鍵位） |
| DRILL | `SELECT` / `K1` / `PLAY` | 公式集 / 模式 / 開始一回合 |
| | `PLAY` | 翻面；答完：記得 |
| | `SEL` / `REC` | 答完：慢 / 不會；VIRTUAL：`REC` 放棄；REAL：`REC` 跳過 |
| STATS | `SELECT` | 捲動 |
| SETTINGS | `SELECT` / `K1` 或 `OCT±` / `PLAY` | 選行 / 改 / 執行 |

## 鍵位

上排是黑鍵，中間是白鍵，最下面是音名。`<` 是 UNDO，`.` 沒有作用。每一種鍵位都是：同一鍵按兩下 = X2，`SEL` + 鍵 = 反方向。在 SETTINGS 的 KEYS 換，EDIT KEYS 可以逐鍵改成自己的（CUSTOM）。

### BLACK KEYS（預設）

白鍵順時針，右邊緊鄰的黑鍵逆時針；`L` 在最左、`R` 在最右。

```
    L'  D'  B'      F'  M'      U'  E'  S'      r'  u'      R'
  L   D   B   x   F   M   y   U   E   S   z   r   u   <   R   .
  F3  G3  A3  B3  C4  D4  E4  F4  G4  A4  B4  C5  D5  E5  F5  G5
```

### TWO HANDS

左手在低音區轉 `L D B`，右手在高音區轉 `R U F`（參考 cstimer 鍵盤配置的精神，不是逐鍵照抄）。

```
    l   B   L'      l'  M'      M   r   R       B'  r'      S
  z'  y'  D   L   U'  F'  x   F   U   R'  D'  y   z   <   x'  E
  F3  G3  A3  B3  C4  D4  E4  F4  G4  A4  B4  C5  D5  E5  F5  G5
```

### SEL

16 個白鍵順時針（按住 `SEL` 逆時針），黑鍵是左邊那個白鍵的 X2。

```
    L2  M2  D2      F2  x2      z2  U2  E2      r2  u2      R2
  L   M   D   B   F   x   y   z   U   E   S   r   u   <   R   f
  F3  G3  A3  B3  C4  D4  E4  F4  G4  A4  B4  C5  D5  E5  F5  G5
```

記號：`M` 跟 `L` 同方向、`E` 跟 `D`、`S` 跟 `F`；小寫是兩層（`r` = `Rw`），`x y z` 跟 `R U F` 同方向。
