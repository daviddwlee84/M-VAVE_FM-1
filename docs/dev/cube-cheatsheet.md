# CUBE 操作速查

[CUBE](cube.md) v0.1 的按鍵一覽。`HOME` 隨時回 MENU；MENU 裡 `SELECT` 選、`PLAY` 進。

## 每一頁

| 頁 | 控制 | 作用 |
|---|---|---|
| TIMER | 任一鍵 | 開始 inspection（開著時）；按住 0.3 秒放開：開始；計時中：停 |
| | `K1` | 剛結束那一筆：OK / +2 / DNF |
| | `SEL` 兩下 | 刪掉剛結束那一筆 |
| | `REC` | 換打亂 |
| CUBE | 琴鍵、`SEL` + 琴鍵 | 轉面、反方向 |
| | UNDO 鍵、`SEL` + UNDO | 退一步、回到復原 |
| | `REC` / 按住 `REC` | 跟著燈打亂 / 直接打亂好 |
| | `PLAY` | 虛擬計時（第一轉開始、復原時停） |
| | `K1` `K2` `K3` / `K4` | 繞 x、y、z 轉視角 / 斜看的 preset |
| | 只按 `SEL` | 鍵位圖 |
| ALGS | `SELECT` / `K1` | 公式集 / case |
| | `PLAY` | 在方塊上播放公式（燈亮鍵位） |
| DRILL | `SELECT` / `K1` / `PLAY` | 公式集 / 模式 / 開始 |
| | `PLAY` / `SEL` / `REC` | 翻面或答對 / 慢 / 答錯（VIRTUAL、REAL：放棄） |
| STATS | `SELECT` | 捲動 |
| SETTINGS | `SELECT` / `K1` 或 `OCT±` / `PLAY` | 選行 / 改 / 執行 |

## BLACK KEYS（預設鍵位）

```
    L'  D'  B'      F'  M'      U'  E'  S'      r'  u'      R'
  L   D   B   x   F   M   y   U   E   S   z   r   u   <   R   ·
  F3  G3  A3  B3  C4  D4  E4  F4  G4  A4  B4  C5  D5  E5  F5  G5
```

上排是黑鍵，下排是白鍵，最下面是音名。`<` 是 UNDO（`E5`），`·`（`G5`）沒有作用。同一鍵按兩下 = X2；`SEL` + 鍵 = 反方向（`x y z` 的反向也這樣按）。其他鍵位見 [CUBE 的鍵位](cube.md#keys)。
