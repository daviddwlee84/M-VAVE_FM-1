# 摩斯電碼機操作速查

韌體 0.1。設計與原理見[摩斯電碼機](morse.md)。

## 任何頁面

| 控制 | 作用 |
|---|---|
| `HOME` | 叫出選單；在選單裡再按一次回到上一頁 |
| `ALGO` 旋鈕 | 直接換頁 |
| `FX` | 聲音開／關。關掉時 `FX` 燈亮，改看琴鍵燈和畫面上的燈號 |
| `K1` | 字元速度 5–40 WPM（預設 20） |
| `K2` | 有效速度（Farnsworth）：字和字之間拉開，5 到字元速度（預設 10） |
| `K3` | 音高 300–1200 Hz（預設 600）。收到的訊號高一個大三度 |
| `MASTER` | 音量 |

設定改完 3 秒後自動存。

## PRACTICE（閃卡）

| 控制 | 作用 |
|---|---|
| `PLAY` | 開始一回合；題目播完後再按是重播 |
| `E4` `F4` `G4` `A4` | 四選一的題目：四個亮燈的鍵對應畫面上四個選項（由左到右） |
| `SELECT` + `SEL` | 也可以轉 `SELECT` 選、按 `SEL` 確定（閃爍的是目前選的） |
| 琴鍵（電鍵） | 「打出來」的題目：畫面出現 `your turn` 後照設定的 keyer 打 |
| `SEL` | 打的題目不會：算錯，顯示答案 |
| 任一琴鍵 | 新字：看完聽完，下一張；答案畫面：不等，直接下一張 |
| `HOME` | 離開，已答的部分會存 |

## KEY（自由發報）

| 控制 | 作用 |
|---|---|
| 琴鍵 | 直鍵：任一鍵。iambic：左半邊 F3–F4 是 dit，右半邊 F#4–G5 是 dah（SETTINGS 可對調） |
| `OCT-` | 清掉畫面上的字 |

白字是自己發的，琥珀色是收到的（MIDI 或電腦送來的文字）。文字上方顯示解碼器聽到的速度和 dah:dit 比例（標準是 3.0）。接著電腦時，發出的按鍵會經 USB 送出（Vail 格式），解出的字也會送給 host。

## TYPE（字母鍵盤）

| 控制 | 作用 |
|---|---|
| 白鍵 | A B C D E F G H I J K L M N O P |
| 黑鍵 | Q R S T U V W X Y Z，最右邊的黑鍵是空白 |
| 按住 `OCT-` | 白鍵變成 `1234567890.,?/=+`，黑鍵變成 `-()'":;@!&$` |
| `OCT+` | 刪掉最後一個字 |
| `PLAY` | 把整行再播一次 |

每按一個字就播出來（也經 USB 送出）。畫面下方是鍵位圖，正在播的字會亮。

## CHART（字表）

| 控制 | 作用 |
|---|---|
| `SELECT` | 移動 |
| `PLAY` / `SEL` | 聽這個字 |

顏色：深紅是剛學、黃是一半、綠是熟了（兩張卡盒號的平均）；幾乎全黑的格子是還沒開的字。

## SETTINGS

`SELECT` 選項目，`OCT-` / `OCT+`（或 `K4`、`SEL`）改值。

| 項目 | 值 |
|---|---|
| SPEED | 字元速度 |
| SPACING | 有效速度（Farnsworth） |
| PITCH | 音高 |
| KEYER | STRAIGHT、IAMBIC A、IAMBIC B |
| PADDLES | LEFT DIT（左 dit 右 dah）或 LEFT DAH |
| SOUND | ON 或 OFF（看燈） |
| CARDS | 每回合 10–30 張 |
| LEARN BY | SOUND（預設，建議）或 SIGHT（顯示點劃）。原因見[先用聽的](morse.md#by-sound) |

## 燈

| 燈 | 意思 |
|---|---|
| 所有琴鍵全亮／半亮 | 自己在發／收到訊號（靜音時就看這個） |
| 四個琴鍵亮、一個閃 | 四選一的選項，閃的是 `SELECT` 選中的 |
| `FX` 亮 | 靜音 |
| `PLAY` 綠 | 電腦端程式連著 |

## 電腦端

```sh
just morse-type            # 解出的字打進 Mac 目前的視窗（要 Accessibility 權限）
just morse-type --dry-run  # 只印出來
just morse-send cq cq de fm1 k   # FM-1 當成收到的播出來
```
